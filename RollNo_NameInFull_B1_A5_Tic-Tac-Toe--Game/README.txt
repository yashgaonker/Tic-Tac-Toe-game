ASSIGNMENT 5 - GUI-BASED JAVA GAME
Game: Tic-Tac-Toe

HOW TO RUN
1. Open this folder in VS Code.
2. Open Terminal > New Terminal.
3. Run:
   cd code
   javac TicTacToeGame.java
   java TicTacToeGame

OOP CONCEPTS
- Classes and objects: TicTacToeGame, HumanPlayer
- Encapsulation: private fields and public getters
- Abstraction: abstract GamePlayer class
- Inheritance: HumanPlayer extends GamePlayer
- Interface: TicTacToeGame implements Resettable
- Polymorphism: HumanPlayer overrides getPlayerType()
- Constructors: initialize players and GUI
- Event handling: Swing button listeners
- Arrays and algorithms: board and winner/draw checking
- Exception handling: guarded look-and-feel setup and invalid square handling
